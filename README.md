# Jurassic Camp: Survival website

Static website for GitHub Pages. Includes homepage, support, and a **draft** privacy policy.

## Publish
1. Create a new **public** repository on GitHub named `jurassic-camp-site`.
2. Upload the contents of this folder to the repository root (not the folder itself). Make sure `index.html` appears at the top level.
3. Go to **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, `main`, and `/(root)`. Save.
4. GitHub provides a site at `https://YOUR-USERNAME.github.io/jurassic-camp-site/`.
5. App Store Support URL: `https://YOUR-USERNAME.github.io/jurassic-camp-site/support.html`
6. App Store Privacy Policy URL: `https://YOUR-USERNAME.github.io/jurassic-camp-site/privacy.html`

## Before App Store submission
- The privacy page is marked as a pre-release draft intentionally. Review the final iOS build, SDKs and data collection, replace provisional language with verified disclosures, and remove the draft notice **before submitting**.
- Verify all descriptions against the actual released gameplay and available controls.
- The website currently uses illustrative styling and a dinosaur emoji, not game screenshots. Add your own screenshots or approved promotional imagery when available.
- This is static hosting: `mailto:` opens the visitor's mail app. A website contact form needs a separate form service or backend.
- Do not upload your game's private source code, credentials, access tokens or signing certificates into this public repository.
